This page reads status.json, a snapshot committed to the repository. It is not a live connection to the node. The age is shown above so you can judge it.

Storage

Two SATA SSDs. sdb (256 GB) holds the OS and is the only drive this Mac will boot. sda (128 GB, /srv/backup) hangs off the old optical-drive header via a ribbon mod and cannot boot — by firmware design, not misconfiguration.

Service health

    Health is measured functionally — each service is probed to see whether it actually answers, rather than asking Docker whether a container is running. A container that is "up" but no longer serving is a failure, and this catches it.

    Backup quorum

    Irreplaceable photographs are replicated from the One Touch drive to the node. Quorum is currently 2 copies (One Touch + fridge). frostbyte is a laptop with no capacity for the full set and holds only small critical items.

    Portals
