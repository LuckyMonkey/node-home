Current operator-facing notes for the hash-first share bridge, compatibility routes, and local history behavior.

Portal Share Lookup Recent Shares Status
Primary Hash-first links /file?h=<shareId> is the primary public bridge shape. /redirect?h=<shareId> remains the browser handoff page.
Compatibility Slug routes still work /f/<slug>, /file/<slug>, and the older query style are still accepted for compatibility and older links.
History Saved recent share hashes Browser-local recent history merges with remote recent shares from the fridge-share service so the portal can restore what was opened recently.
Legacy Old ids are preserved The fridge-share service recomputes a canonical short shareId and preserves older ids in legacyShareIds so older links still resolve.
Current public limitation. The browser bridge works today, but direct raw byte serving from the root fridge.run hostname still needs a real edge proxy or tunnel in front of the fridge service.

Use /status for the live bridge health view, or /shares to inspect the current recent-share list.
