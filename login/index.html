Sign in to the node

Reading the dashboard needs no account. Signing in is for changing things.

This hands you to Google, which authenticates you, and then to the node's Apps Script endpoint. That endpoint reads the identity Google supplies server-side and checks it against an allowlist before returning anything. It fails closed: an unknown account — or an unset allowlist — denies access.

This page is static and therefore cannot enforce identity itself, so it doesn't try to. Nothing here is a security control, and knowing the endpoint URL grants nothing on its own. The check happens server-side, where your browser cannot reach it.
